# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Report a vulnerability privately through
[GitHub security advisories](https://github.com/tmctec/tuiframework/security/advisories/new).
Do not open a public issue for it.

Include the affected version, a description of the problem, and the steps or
code that reproduce it. You get a reply within seven days.
